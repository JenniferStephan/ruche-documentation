# Contribuer à cette documentation

Cette documentation est un produit : elle s'améliore grâce à celles et ceux qui l'utilisent. Tout le monde peut proposer une modification. L'équipe de la Ruche relit et publie.

## Corriger ou compléter une page

1. Sur la page concernée, clique sur le crayon :material-pencil: en haut à droite.
2. GitHub te demande de te connecter (crée un compte gratuit si besoin), puis te propose de créer ta propre copie : accepte.
3. Modifie le texte directement dans l'éditeur. L'onglet « Preview » montre le rendu.
4. En bas, décris ta modification en une phrase et clique sur « Propose changes », puis « Create pull request ».

C'est tout. Ta proposition arrive chez l'équipe de la Ruche, qui la relit, peut te poser une question en commentaire, puis la publie. Le site se met à jour automatiquement quelques minutes après.

## Signaler sans corriger

Tu as repéré un manque mais tu ne sais pas quoi écrire ? [Ouvre un signalement](https://github.com/jenniferstephan/ruche-documentation/issues/new/choose). C'est tout aussi utile.

## Quelques repères d'écriture

- On tutoie le lecteur, on écrit court, à la voix active.
- On documente **ce qui n'est vrai qu'ici** : le ministère, ses circuits, ses outils, ses contacts. Pour la méthode produit générale, on renvoie vers beta.gouv.fr.
- Les acronymes sont développés à leur première apparition.
- Pas de données personnelles ni d'information non publique.

## Mémo de mise en forme

| Tu écris | Tu obtiens |
|---|---|
| `**gras**` | **gras** |
| `[texte](autre-page.md)` | un lien vers une autre page |
| `## Titre` | un intertitre |
| `- élément` | une liste à puces |

Pour un encadré :

```
!!! warning "Attention"
    Le texte de l'encadré, décalé de quatre espaces.
```

Types disponibles : `note`, `info`, `tip`, `success`, `warning`, `danger`.

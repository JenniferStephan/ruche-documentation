# Checklist d'embarquement

Le récapitulatif cochable. Ce que la Ruche fait, ce que tu fais.

Cette page transforme nos bonnes pratiques en engagements vérifiables. Si une case de la colonne de gauche n'est pas cochée, c'est à nous de la cocher.

## Avant l'arrivée

| La Ruche                                                            | La personne qui arrive                        |
| ------------------------------------------------------------------- | --------------------------------------------- |
| Envoie le mail d'accueil complet                                    | Confirme sa disponibilité et sa date          |
| Confirme la date de démarrage par écrit                             | Transmet les pièces administratives demandées |
| Demande les accès                                                   | —                                             |
| Désigne le référent, et un référent de secours en période de congés | —                                             |
| Sécurise le bon de commande (prestataires)                          | Envoie son devis (prestataires)               |
| Organise la rencontre avec l'équipe produit                         | —                                             |

## Premier jour

| La Ruche                                 | La personne qui arrive                   |
| ---------------------------------------- | ---------------------------------------- |
| Vérifie que les accès fonctionnent       | Teste ses accès et signale ce qui manque |
| Partage le modèle des dix premiers jours | Installe ses outils                      |
| Présente l'équipe produit                | Se présente sur le canal de bienvenue    |
| Indique les canaux à rejoindre           | Rejoint les canaux                       |

## Première semaine

| La Ruche                               | La personne qui arrive                       |
| -------------------------------------- | -------------------------------------------- |
| Tient le point de 20 minutes           | Suit l'onboarding du réseau beta.gouv        |
| Donne les repères sur le ministère     | Identifie sa direction métier et son sponsor |
| Explique l'articulation avec le réseau | Signale ce qui coince                        |

## Premier mois

| La Ruche                                        | La personne qui arrive                                  |
| ----------------------------------------------- | ------------------------------------------------------- |
| Invite à l'accueil collectif mensuel            | Participe                                               |
| Tient un point hebdomadaire de 20 minutes       | Assiste à au moins une démonstration d'une autre équipe |
| Cale le point budget                            | Lit les pages budget qui la concernent                  |
| Recueille le retour d'expérience d'embarquement | Le donne franchement                                    |

***

!!! info "Pourquoi une checklist ?"
    Parce qu'un bon accueil ne doit pas dépendre de qui accueille. Les gestes qui marchent — le mail complet, le modèle des premiers jours, le point en tête à tête, le coach présent — existaient déjà. Ils étaient irréguliers. Ils sont désormais dus.
